# AI Agent 与工具调用

一个 AI Agent 和普通聊天机器人的区别在于：Agent 能自己决定调用工具来完成任务。

工作方式是循环（loop）：
1. 把用户消息和可用工具列表一起发给模型
2. 模型判断要不要调用工具；要的话返回工具名和参数
3. 程序真正执行这个工具，把结果作为“工具消息”再喂回模型
4. 模型根据工具结果生成最终回答

这个“决定调用 → 执行 → 回填 → 再生成”的过程就是一次 agent 循环。
如果任务复杂，可以多轮循环，直到模型不再需要调用工具。

工具本质上就是普通的 Python 函数，但要用 JSON Schema 描述它的名字、用途和参数，
这样模型才知道什么时候该用它、怎么传参。

本项目目前只有两个工具：calculator（计算器）和 get_weather（天气）。
