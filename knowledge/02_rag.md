# RAG（检索增强生成）

RAG 全称 Retrieval-Augmented Generation，即检索增强生成。

它的核心思想是：大语言模型本身不知道你的私有资料，所以先把资料切成小片段、
转成向量存进向量库；当用户提问时，先把问题也转成向量，从库里找出最相关的几个片段，
再把这些片段连同问题一起交给大模型，让它基于这些片段来回答。

一个典型的 RAG 流程包含五步：
1. 加载文档（load）
2. 切块（chunk）
3. 向量化（embedding）
4. 存入向量库（index）
5. 检索（retrieve）出 top-k 片段，拼进提示词

切块时通常会让相邻片段有重叠（overlap），避免一句话正好被切断而丢失上下文。

RAG 的好处是：答案有据可查、可以引用来源，并且更新知识只需更新文档，不用重新训练模型。

Embedding 模型负责把文本转成向量，语义相近的文本在向量空间里距离更近，
常用余弦相似度（cosine similarity）来衡量两个向量的接近程度。
