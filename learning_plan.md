# Learning plan

Fit score: **55/100** — Partial match

**Gaps to close:** Azure DevOps, SAP HANA / SAP product landscape, Performance‑debugging of HANA queries, Modern cloud architecture with hyperscalers (RISE with SAP), SRE concepts (HA, DR, monitoring), Advanced SQL performance tuning

## 1. Azure DevOps Pipelines  _high priority_
- **Why:** Needed to integrate database‑operations and lifecycle‑processes into the CI/CD pipelines the job requires.
- **How:** Complete Microsoft Learn Azure DevOps learning path, then build a sample pipeline that runs Python scripts and SQL migrations.
- **Effort:** 2‑3 weeks

## 2. SAP HANA fundamentals & SQL performance tuning  _high priority_
- **Why:** Core part of the role is performance‑debugging and optimisation of HANA queries.
- **How:** Take the free SAP HANA Academy course, practice with a HANA Express trial, focus on EXPLAIN plans and index strategies.
- **Effort:** 3‑4 weeks

## 3. RISE with SAP & hyperscaler cloud architecture  _medium priority_
- **Why:** Job expects design of scalable cloud platforms based on SAP’s RISE model.
- **How:** Study SAP’s RISE documentation, watch webinars on SAP on AWS/Azure/GCP, and create a small proof‑of‑concept deployment.
- **Effort:** 2 weeks

## 4. SRE basics (HA, DR, monitoring)  _medium priority_
- **Why:** Automatisierte Lösungen für High Availability und Disaster Recovery are required.
- **How:** Follow Google SRE Site Reliability Engineering book chapters, implement monitoring with Prometheus/Grafana on a Linux VM.
- **Effort:** 2 weeks

## 5. Advanced SQL performance tuning (beyond basics)  _low priority_
- **Why:** Will help optimise database operations across any platform, including SAP HANA.
- **How:** Read "SQL Performance Explained", practice on MariaDB/SQLite and then on HANA Express.
- **Effort:** 1‑2 weeks
